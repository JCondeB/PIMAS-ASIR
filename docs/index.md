
# Proyecto Intermodular ASIR

## Asesoría Tajo Gestión, S. L.

Proyecto de diseño e implementación de una infraestructura informática para una asesoría ficticia de 18 empleados.

### Objetivo

Desplegar una infraestructura virtual con redes separadas para usuarios y servidores, un cortafuegos OPNsense y un servidor Ubuntu Server.

### Estado actual

- VMware Workstation 16 Pro configurado.
- OPNsense 26.7 instalado y operativo.
- Ubuntu Server 26.04.1 LTS instalado.
- Redes virtuales VMnet8, VMnet2 y VMnet3 configuradas.
- Conectividad, SSH y filtrado de tráfico comprobados.
- GLPI y MariaDB pendientes de instalación en fases posteriores.
